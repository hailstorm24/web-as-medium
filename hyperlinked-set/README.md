This project catalogs Rolling Stone's Best Albums of the 2020s, exploring how collaborations influence similarities across the music industry.

The chord diagram shows shared credits across albums; chords are drawn to connect each pair of albums that share a given contributor.
Chords are colored by album and saturated by similarity; brighter chords connect more similar albums, computed according to methodology outlined in
Logan & Salomon's "A Music Similarity Function Based on Signal Analysis".

Use the side panel to add or remove albums from the ring. Select chords to traverse the graph by individual or covers to view contributors by album.
